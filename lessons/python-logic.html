الصف المظلَّل هو الحالة الحالية في المختبر.

ترتيب الأولوية

notثمandثمor

لذلك يُحسب True or False and False هكذا: False and False أولًا فتنتج False، ثم True or False فتكون النتيجة True. استخدم الأقواس عند الحاجة لتغيير الترتيب.
