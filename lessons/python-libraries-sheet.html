السؤال الأول
math.sqrt(64)8.0math.ceil(4.1)5
math.pow(3, 2)9.0math.floor(9.9)9
math.floor(math.sqrt(20))4random.randint(1, 3)1 أو 2 أو 3
السؤال الثاني
import math → math.sqrt(81) from math import sqrt → sqrt(81) import math as m → m.sqrt(81)
السؤال الثالث

البرنامج الأول: استوردنا الدالة randint وحدها، فالاسم random غير معرَّف (NameError). التصحيح: x = randint(1, 10) — أو تغيير سطر الاستيراد إلى import random.

البرنامج الثاني: الثابت pi موجود داخل المكتبة math، فيجب كتابته math.pi. التصحيح: area = math.pi * r * r

السؤال الرابع
import random d1 = random.randint(1, 6) d2 = random.randint(1, 6) total = d1 + d2 print("النرد الأول:", d1) print("النرد الثاني:", d2) print("المجموع:", total) if total == 12: print("فزت بالجائزة!")

تُقبل أي صيغة صحيحة؛ مثل from random import randint مع استدعاء randint(1, 6) مباشرة.
